# 雙相機單張量測版本

開發分支：`codex/dual-camera-snapshot`。

## 模型

- 專案根目錄 `best.pt`：只使用 comb 類別。
- 專案根目錄 `best_shank.pt`：使用 shank 模型。
- 模型檔不隨 Git 傳送；部署到 Ubuntu 時須另外複製這兩個檔案。

## 操作

1. 以原本方式啟動 `streamlit run src/app.py --server.port=8501`。
2. 在相機調整頁選擇兩個不同的 camera ID，確認左右畫面。
3. 在比例尺校正頁拍攝雙相機校正照片，分別輸入比例尺長度、點選兩端，再確定校正。兩台相機各自使用獨立 cm/pixel。
4. 在表型輸入頁掃描 Chicken ID。按原本量測按鈕（或實體按鈕的 r 熱鍵），兩台相機各取得一張新照片，加入背景推論佇列。
5. 兩個模型均成功後，雞冠面積、腳脛寬度與長度、重量合併寫入同一隻雞的紀錄，沿用既有分級與燈號流程。

照片使用同一次操作觸發，並限制讀取時間差在 250 ms 以內；這不是硬體同步曝光。任一相機或辨識失敗時，不覆寫量測資料。

重量仍採原本 2 秒讀值平均；本次只取消影片與多影格表型平均。校正保留於瀏覽器工作階段，重啟後須重新校正。更換相機或解析度也須重新校正。

原始照片存於 `data/snapshots/<任務識別碼>/`；標註圖片與量測資訊存於 `data/sam2_inference_outputs/<任務識別碼>/`。

## 測試

從儲存庫根目錄執行 `python -m unittest discover -s chicken_grading_simulator/tests -v`。自動化測試使用模擬相機與隔離資料庫，不代表實體相機、秤重或燈號已通過現場驗收。
